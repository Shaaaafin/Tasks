# UI evidence

`sources.json` lists the exact download URL and role for each saved image. These are research references only and are not app assets.

- `google-tasks-01` through `10`: Google’s Play Store marketing gallery, retrieved 2026-10-17. Some images show iOS, tablets, Gmail, or Calendar. Use these only to understand shared task rows and dialogs; do not reproduce the excluded Google integrations.
- `android-home-dark-2024.jpg`: actual Android dark-theme card layout and FAB.
- `android-home-dark-completed-2024.jpg`: filename follows the source sequence; the image actually shows the **light** theme. Confirms separate completed card and dynamic color treatment.
- `android-design-comparison-2024.jpg`: before/after Android navigation reference. The bottom app bar is the older version.
- `android-deadline-editor-2025.jpg`: separate deadline and scheduled date/time, rounded editor surface, bottom completion button.
- `android-widget-old-2026.jpg`, `android-widget-new-2026.jpg`: widget refresh, including the pill-shaped plus button and dynamic colors.
