# Store metadata

The Android store text is maintained in `metadata/android/en-US/`. It currently uses the application's working title, Tasks.

Place the final icon at `metadata/android/en-US/images/icon.png` and device screenshots in `metadata/android/en-US/images/phoneScreenshots/`. Number screenshot filenames in display order.

Changelog filenames correspond to the Android version code, not the version name. Keep each changelog within 500 characters and the short description below 80 characters.

See [the screenshot guide](../docs/SCREENSHOTS.md) and [F-Droid preparation](../docs/FDROID.md).
